# Imagens do site

Organização reservada para os materiais reais da oficina:

- `hero/`: fachada ou caminhão em manutenção usado no topo;
- `oficina/`: espaço interno, equipamentos e equipe;
- `servicos/`: imagens de apoio dos serviços;
- `portfolio/`: fotos dos trabalhos realizados;
- `clientes/`: marcas autorizadas dos clientes;
- `logo/`: identidade oficial quando estiver disponível.

Ao adicionar itens ao portfólio ou clientes, atualize os respectivos arquivos em `src/data/` e altere `published` para `true`.
